# 디자인씽킹 피드백 그리드

## GitHub Pages 게시 방법
1. ZIP 파일의 압축을 풉니다.
2. GitHub에서 새 저장소를 만들거나 사용할 저장소를 엽니다.
3. Add file → Upload files에서 index.html과 .nojekyll, README.md를 업로드합니다.
   index.html은 저장소 첫 화면에 보여야 합니다. ZIP 파일 자체나 상위 폴더를 올리지 마세요.
4. Commit changes를 누릅니다.
5. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
6. Branch는 main, 폴더는 /(root)로 선택하고 Save를 누릅니다.
7. 배포가 완료되면 Pages 화면의 Visit site를 누릅니다.

저장소 이름만 보인다면 index.html이 저장소 최상위에 있는지, 파일 이름이 정확한지 확인하세요.
기존 사이트를 유지하려면 새 저장소에 올리세요. 같은 이름의 index.html을 덮어쓰면 해당 페이지가 바뀝니다.

## 사용 방법
발표자 선택 → 요약서 보기 또는 패들렛에서 보기 → 피드백 작성 → 피드백 복사 또는 인쇄 / PDF.
각 칸 지우기, 선택한 과제 지우기, 모두 지우기, 지우기 되돌리기를 제공합니다.

## 기록과 공유
- ChatGPT 로그인 없이 작동하는 정적 웹앱입니다.
- 피드백은 작성한 기기의 브라우저에 자동 저장됩니다. 다른 기기나 사용자와 자동 공유되지 않습니다.
- 패들렛에 의견을 남기려면 피드백 복사 후 직접 댓글에 붙여 넣으세요.
- 지우기 되돌리기는 현재 페이지를 닫거나 새로고침하기 전, 마지막 지우기 작업에 적용됩니다.
- index.html에 발표자 이름과 계획서 요약 9편이 포함되어 있습니다. 공개 GitHub Pages에 게시하면 방문자가 이 내용을 볼 수 있습니다.
- 빌드나 설치 없이 index.html을 열어 사용할 수도 있습니다.
